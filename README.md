# With Windows

面向 Windows 11 的 WinUI 3 轻量托盘工具箱，支持 Windows 11 22H2 及以上版本，仅提供 x64 安装器与便携包。

</p>

> 本项目由 AI 协作完成：代码、文档与迭代均经 AI 生成和优化。

## 功能

- **记事**：自动保存、查找替换和状态栏。
- **待办**：完成状态、到期时间与 Windows 原生提醒。
- **AI 对话**：兼容 OpenAI 接口，支持流式对话、图片粘贴和脚本生成。
- **脚本**：使用 C# 编写脚本，支持手动或定时执行、语法高亮和运行日志。
- **投影**：保存投屏模式并一键切换。
