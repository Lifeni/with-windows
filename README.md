# <img src="docs/images/with-windows.png" width="40" alt="With Windows"> With Windows

Windows 11 的轻量托盘工具箱，使用 WinUI 3 构建。关闭窗口后继续驻留托盘，随时通过托盘菜单或快捷键唤出。

- **记事**：自动保存的纯文本编辑器，带查找替换和状态栏。
- **待办（开发中）**：添加、完成、删除待办，并支持单项到期提醒；提醒仅在应用驻留托盘时生效，完全退出后不会触发。
- **AI 对话**：连接 OpenAI 兼容接口，支持流式回复和图片粘贴。
- **投影**：保存投屏模式并一键切换。

## 下载

前往 [GitHub Releases](https://github.com/Lifeni/with-windows/releases/latest) 下载最新正式版。当前正式版为 `v0.6.0`，暂不包含待办页。

支持 Windows 11 22H2 及以上版本，仅提供 x64 安装器与便携包。安装器目前未签名，首次运行时 Windows 可能显示 SmartScreen 提示。
